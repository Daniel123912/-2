# Черновик карточки RuStore — Питомец Финни

- **Название:** Питомец Финни
- **Package name:** `ru.moscow.finny.pet`
- **Версия:** 1.0.0 (build 1)
- **Категория:** Образование / Дети
- **Возрастная маркировка:** 0+ / для детей при участии взрослого (без сбора ПДн, без платежей)

## Краткое описание

Игровое приложение, где ребёнок 7–11 лет учится планировать бюджет, различать нужные и желаемые покупки и копить на цель вместе с виртуальным питомцем.

## Полное описание

«Питомец Финни» — бесплатный просветительский прототип. Ребёнок получает игровую валюту, составляет план личного бюджета, совершает покупки, выполняет задания по финансовой грамотности и откладывает средства на понятную цель. Состояние и рост питомца зависят от финансовых решений, ошибки безопасны и объясняются простыми словами.

Приложение работает без регистрации, без рекламы и без реальных платежей. Данные хранятся только на устройстве. Взрослый может посмотреть прогресс и сбросить тестовый профиль через защищённый раздел.

## Материалы для витрины

- Иконка 512×512 px (подготовить отдельно)
- Не менее 3 скриншотов: создание питомца, главный экран, бюджет/накопления
- Обоснование возрастной маркировки: нет насилия, платежей, чатов и сбора данных ребёнка

## Сборка

```bash
flutter build apk --release
```
